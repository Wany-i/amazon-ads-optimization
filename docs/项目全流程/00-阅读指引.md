## 三、文中的标记怎么读

### 证据强度四档（最重要的约定）

| 标记 | 含义 | 你该怎么用 |
|---|---|---|
| **多源验证** | 多个相互独立来源支持 | 可以作为较强结论使用，但仍要核对适用条件 |
| **单一来源** | 只有 1 个来源支持 | 只能参考，不能当成行业共识 |
| **经验起点** | 无外部来源，是项目设定的起始值 | 必须用自己的账户和类目数据校准 |
| **待补 / 未验证** | 明确尚未验证 | 不要当结论，也不要直接用于自动执行 |

> 来源数量只是最低门槛，不替代适用性判断。一个在北美家居类目成立的阈值，不天然适用于其他站点、类目或阶段。

### 事实 vs 推断

- **事实**：能追到来源，例如官方文档、公开文章、开源实现、实测记录。
- **推断**：文档作者的判断，正文会明确写「这是推断」。

读到时请分开对待。自动化系统尤其不能把推断包装成硬规则。

## 四、术语速查

| 术语 | 一句话 |
|---|---|
| **ACoS** | 广告花费 ÷ 广告销售额，衡量广告自身效率 |
| **TACoS** | 广告花费 ÷ 总销售额（含自然），衡量广告对整店的影响 |
| **盈亏平衡 ACoS** | 广告前单位贡献 ÷ 售价；超过它通常意味着广告在贴钱 |
| **目标 ACoS** | 在盈亏平衡线上再留出目标净利后的经营目标 |
| **可接受 CPC** | 售价 × 转化率 × 目标 ACoS，是出价天花板 |
| **动态点击阈值** | 1 ÷ 转化率，用于判断样本是否足以支持判断 |
| **收割** | 把已验证的搜索词迁到独立 Exact 活动，以便单独控制出价 |
| **份额漏斗** | SQP 报告的曝光、点击、加购、购买四份额，用于定位短板 |
| **规则层** | 可解释、可计算、可审计的主决策路径 |
| **影子层** | 另一套模型只作为第二意见，不进入决策主路径 |
| **分歧检测** | 规则层与影子层判断不一致，分歧本身就是案例模糊的信号 |
| **门控** | 按置信度和风险阈值决定自动执行还是转人工 |

## 五、三个需要先建立的认知

### 1. 「可验证的」和「只能练的」是两回事

投放能力中，概念、公式、机制、流程和边界有相对明确答案；判断力、阈值感、类目直觉则主要依赖实践。

> 【**经验起点，无外部来源**】“约 40% 能学、60% 只能练”是用于说明学习边界的粗估，不是统计结论。

### 2. 自动化最贵的错误不是判断错，而是判断错后被批量放大

手工优化判断错还能逐步修正；批量执行会把同一种错误同步放大到很多对象上。所以规则层必须同时约束：

- 什么条件下才能判断；
- 单次最多改多少；
- 哪些动作必须人工确认；
- 出错后怎样回滚或止损。

### 3. 结论必须能落到「改什么、改成多少、为什么」

每条建议都应能追溯到输入数据、计算公式、阈值和适用边界。没有依据的建议无法复盘，也无法在异常时定位责任点。

## 八、本篇的局限 / 未验证项

本篇是导读，不含独立业务结论。以下内容未经验证：

- **阅读顺序**：按项目实际推进逻辑整理，尚未经过多人使用验证是否最优。
- **术语速查**：只覆盖高频术语，未做完整性和行业统一口径校验。
- **“约 40% 能学、60% 只能练”**：经验判断，无外部来源，仅用于说明学习边界。
- **“只读三篇”的推荐**：主观选择，不是效果验证结论。
- **外部仓库结构**：链接目标可能随后续版本调整；若页面变化，以该仓库当前目录和说明为准。
- **学习材料适用性**：材料中的市场规则、工具能力和数据源会变化，使用前应重新核对时效性与许可条件。

> 最后提醒：文中标为「经验起点」或「待补 / 未验证」的内容，是为了标明边界，不是让你直接拿去自动执行。
