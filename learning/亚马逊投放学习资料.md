# 第一部分：地基

---

## 第 1 章 先把语言统一

### 1.1 三个最容易搞混的指标

| 指标 | 公式 | 分母是什么 |
|---|---|---|
| **ACoS** | 广告花费 ÷ **广告销售额** | 只看广告带来的销售额 |
| **ROAS** | 广告销售额 ÷ 广告花费 = 1 ÷ ACoS | 与 ACoS 互为倒数 |
| **TACoS** | 广告花费 ÷ **总销售额（广告 + 自然）** | 看广告对整店的健康度 |

**关键区别**：ACoS 衡量广告自身效率，TACoS 衡量广告对整店的影响。

**不要同时优化 ACoS 和 ROAS** —— 它们是同一个数的倒数，同时盯着会自我矛盾。通常只用 ACoS。

### 1.2 为什么 TACoS 上升不一定是坏事

这是新手最容易误判的地方。

| 阶段 | TACoS 上升意味着 |
|---|---|
| **推新品 / 抢排名期** | 这是**投资**。要看的是自然排名与自然单占比有没有跟着涨 |
| **成熟期** | 广告在**蚕食自然位**，要收 |

**判断信号：看广告订单占比**

- 广告单占比上升，**总单量不变** → 蚕食（坏）
- 广告单占比上升，**总单量同步上升** → 增量（好）

| 阶段 | 广告单占比参考（经验起点） | 关注点 |
|---|---|---|
| 新品期 | 50%~80% | 排名、评论、自然单是否启动 |
| 成长期 | 30%~50% | TACoS 是否随自然单下降而下降 |
| 成熟期 | 15%~30% | 利润、防守竞品 |
| 清库存 | 不限 | 周转天数与总毛利，不看 ACoS |

### 1.3 其余常用指标

| 指标 | 公式 | 用途 |
|---|---|---|
| **CTR** | 点击 ÷ 曝光 | 广告位吸引力（受主图/价格/相关性影响） |
| **CVR** | 订单 ÷ 点击 | **出价能力的核心乘数** |
| **CPC** | 花费 ÷ 点击 | 实际成交价，不是出价 |
| **IS（曝光份额）** | — | 低 = 被预算或出价卡住 |

> **一个认知**：CVR 越高，你能承受的 CPC 越高。这是后面所有出价公式的基础。

### 1.4 三种广告类型

| 类型 | 位置 | 前提 |
|---|---|---|
| **SP（商品推广）** | 搜索结果 + 商品详情页 | 无门槛，新手从它开始 |
| **SB（品牌推广）** | 搜索结果顶部，带品牌素材 | **需要品牌备案** + 素材落地页 |
| **SD（展示型推广）** | 站内外再营销 | 需受众或商品定向基础 |

**建议顺序**：**第一轮只用 SP**，拿到基础的商品与搜索词反馈。SB/SD 留给已有品牌素材与目标受众的项目。

## 第 2 章 经济账（整个体系的地基）

> **这一章是唯一能"算对"的部分。** 公式记错，后面所有判断都是错的。

### 2.1 盈亏平衡 ACoS

**定义**：广告花费最多能占广告销售额多少，这一单才不亏。

```
售价
 − 产品成本
 − FBA 配送费
 − 平台佣金（售价 × 佣金率）
 − 头程分摊（每件）
 − 仓储/其他分摊（每件）
 − 退货损耗（售价 × 退货率 × 损失率）
= 单位广告前贡献

盈亏平衡 ACoS = 单位广告前贡献 ÷ 售价
```

**官方口径一致**：官方 `acos-advertising-cost-of-sales` 指南原文——
> *"Break-even ACOS is directly linked to your profit margin. In order to maintain a profit,
> your Amazon ACOS needs to be lower than your profit margin. Otherwise, you will be spending
> more on ads than you're earning."*

我们只是把扣项做得更细（多扣头程与退货损耗）。

### 2.2 ⚠️ 退货损耗是最常被漏掉的一项

服装/家居类目退货率 10%~30%。**不扣退货会系统性高估可承受 ACoS。**

举例：售价 $40、退货率 20% 时不扣减，盈亏平衡 ACoS 会被高估约 20 个百分点 ——
这意味着你会以为"ACoS 45% 还能接受"，而实际上你已经在亏钱。

### 2.3 完整算例

**参数**：售价 $39.99、产品成本 $8、FBA $7.5、头程 $3、佣金 15%、退货率 5%、退货损失率 100%

| 项 | 金额 |
|---|---|
| 售价 | $39.99 |
| 产品成本 | −$8.00 |
| FBA | −$7.50 |
| 头程 | −$3.00 |
| 平台佣金（15%） | −$6.00 |
| 退货损耗（5% × 100%） | −$2.00 |
| **单位广告前贡献** | **$13.49** |

```
盈亏平衡 ACoS = 13.49 ÷ 39.99 = 33.74%   （ROAS 2.96）
```

**读法**：ACoS 高于 33.74% 就是亏的；等于 33.74% 是白干。

### 2.4 目标 ACoS：比盈亏平衡线更该用的数

**盈亏平衡线是红线，目标 ACoS 才是日常调优的靶心。**

有两种等价表达方式：

**方式一（从利润倒推）**
```
目标 ACoS = (单位广告前贡献 − 目标单件净利) ÷ 售价
```
例：贡献 $13.49、目标净利 $6 → (13.49 − 6) ÷ 39.99 = **18.74%**

**方式二（从策略姿态出发）**
```
目标 ACoS = 盈亏平衡 ACoS × 策略乘数
```

| 策略 | 乘数（经验起点） | 含义 |
|---|---|---|
| **launch** | 1.40 × | 推新品买排名，利润后置 |
| **dominate** | 1.15 × | 抢类目份额 |
| **grow** | 1.10 × | 要自己养活自己 |
| **maintain** | ≤ 1.00 × | 维持 |

**两条衍生规则（很重要）**：

1. **「砍」跑上限、「加」跑裸盈亏线** —— 允许亏损到上限（ceiling），但只对**真正赚钱**（低于裸盈亏线）的对象加码。否则你会给一个本来就在亏的词加预算。
2. **目标是产品级的，不是账户级的** —— 原话：*"A 35% ACoS is excellent on a 55%-margin product and ruinous on a 20%-margin one."* 同一个数字在一个品上是胜利、在另一个品上是灾难。

### 2.5 可接受 CPC：把 ACoS 目标翻译成出价

```
可接受 CPC = 售价 × 转化率 × 目标 ACoS
```

**这是最有用的一条** —— 它把「出价该多少」变成算术题。

**例**：售价 $40、CVR 8%、目标 ACoS 25% → 可接受 CPC = 40 × 0.08 × 0.25 = **$0.80**

- 当前 CPC $1.10 > $0.80 → **该词结构性亏损**
- 降价或优化转化，**不是靠加预算能救的**

**转化率越高，能承受的 CPC 越高。** 这就是为什么提升 CVR 比压 CPC 更有杠杆。

### 2.6 动态点击阈值

```
需要的点击数 = 1 ÷ 转化率
```

**判断一个词"该不该否定"要用这个数，而不是固定值。**

| CVR | 出 1 单需要 |
|---|---|
| 20% | 5 次点击 |
| 9% | 约 11 次 |
| 8% | 约 12~13 次 |
| 3% | 约 33 次 |

**为什么不能用固定阈值**：独立来源原话——
> *"Negate after 10 clicks with no sales" is the advice everyone gives and **it's wrong for most products**.
> The right number comes from your own conversion rate... **Same rule, different number, because it's derived from the product.***

**重点排查线**：中文独立来源给出的经验是**出单所需点击数的 2.5~3 倍**
（例：CVR 8% 的产品，30~40 次点击仍 0 单，才进重点排查名单）

**单词自身无转化时**：用**品类兜底 CVR**（全量订单 ÷ 全量点击）来推。

## 第 3 章 广告结构与匹配方式

### 3.1 层级关系

```
广告活动（Campaign）  ← 广告类型、每日预算、起止日期、竞价策略、广告位设置
 └ 广告组（Ad Group）  ← 承载推广商品与投放对象
    └ 投放对象         ← 关键词 / 商品 / 类目 / 自动匹配
```

**分层原则**：只要两个商品的**目标、预算或调整方式不同**，就先分到不同**活动**。
需要给同一活动里的商品分开看词、出价或搜索词时，再拆**广告组**。

### 3.2 一个活动一个目标（最常被违反的原则）

新建活动时先写清这次投放要回答什么问题：

- 新品需要积累早期搜索词 → **测词活动**
- 主推款需要覆盖一批已确认相关的核心词 → **核心词活动**
- 某个商品需要测试竞品详情页上的商品投放 → **商品定投活动**

> **一个活动同时承担找词、测图、推新品和清库存，后续很难判断该调哪个参数。**

**目标旁边写一个复查日期**，给广告获得展示、点击和归因数据留出时间。

### 3.3 四种匹配方式的角色分工

**不要问「哪种匹配方式更好」，要问「当前阶段该把钱配给谁」。**

| 匹配方式 | 角色 | 加预算的时机 |
|---|---|---|
| **Auto** | 探索 —— 发现新需求、新搜索词 | 目标是「找机会」时 |
| **Exact** | 放大 —— 承接已验证的高效流量 | 目标变成「放大增长」时 |
| **Broad** | 扩量 —— 覆盖变体与长尾 | 需要铺量时 |
| **Phrase** | 覆盖 —— 兜住中间意图 | 谨慎；大促期易吸低意图流量 |

**阶段对应**：找机会 → 向探索倾斜；放大增长 → 向已验证流量倾斜；进入利润阶段 → 优化结构提高效率，而不是继续无节制扩量。

**一个实测参考**（单一来源）：某次大促中 **Auto Loose Match** 挖出 38 个全新出单词，
CVR +49%、ACoS −24%；而 **Phrase Match** 因吸收大量低意图流量效率下降。
**注意**：Phrase 表现差 ≠ Phrase 没用 —— 它承担覆盖任务，问题在大促期低意图流量涌入时没有及时加否定词。

### 3.4 投词前的相关性四问

**相关性是关键词投放的第一道筛选。** 原话：
> 「一个词有搜索量、有建议竞价，甚至竞争对手在投放，**都不能单独说明它适合你的商品**。」

四问（**出现明确冲突就先不投**）：

1. 搜索这个词的买家，找的是不是你的**产品类型**？
2. 词里包含的**尺寸、材质、功能、数量或人群条件**，是否与商品一致？
3. 商品详情页能否在主图、标题、要点中**说明这个词所代表的需求**？
4. 即使点击后没有立刻下单，这个词是否仍值得**为测试目的保留**？

**判断顺序固定为：相关性 → 匹配方式 → 竞价。**
顺序反了就会出现「竞价调得很精细，但投的词本身就不对」。

### 3.5 建活动前的 7 项准备

| # | 准备项 | 要点 |
|---|---|---|
| 1 | 分清活动与广告组 | 目标/预算/调整方式不同 → 分活动 |
| 2 | 检查商品是否适合推广 | **库存紧张、售价即将变化、页面还在修改 → 先处理，或从首批排除** |
| 3 | 给每个活动写具体目标 | + 复查日期 |
| 4 | 选合适的广告类型 | 第一轮只用 SP |
| 5 | 整理定向清单与排除清单 | 投放对象/匹配方式/初始竞价/理由/关注信号 |
| 6 | 设定每日预算与初始竞价 | 先写测试周期总投入，再换算每日预算 |
| 7 | 固定命名规则 + 启动记录 | 例：`US_ASIN-SP-AUTO_测词_202608` |

**新手最常漏的三件事**：① 同一活动放进太多目的不同的商品 ② 把自动与手动混在一起 ③ 没有启动时记录。

### 3.6 初始出价与日预算

**锚点**：Exact 的**亚马逊建议出价**（来自真实竞价数据，比猜好）

| 活动/匹配 | 相对锚点 |
|---|---|
| Exact（锚点） | 100% |
| Phrase | 85% |
| Broad | 80% |
| Auto | 75% |

> 早前写法是 Auto 为 50%~70%，独立实现给的是 75%。**区间本身无共识，按自家数据校准。**

**日预算 = 该活动的预期 CPC × 倍数**（不是拍出来的）

| 活动类型 | 倍数 | 逻辑 |
|---|---|---|
| Broad seed | 10 × | |
| Auto / Phrase / Exact-stacked | 8 × | |
| Exact-single | 5 × | |

**另一种等价表述**（中文来源）：「**每日预算至少够买到 1 个订单所需的点击量**」

即：`日预算 ≈ (1 ÷ CVR) × CPC`

> 倍数 8~10 相当于假设 CVR 在 10%~12.5%。**若你的 CVR 明显低于此（如 4%），8 倍是不够的，应按 1÷CVR 反算。**

**两条纪律**：① 最小日预算 $5（低于此收集不到数据）② 上线前把月度总额加起来看一遍。

## 第 4 章 九层诊断框架

### 4.1 为什么顺序不能跳

**上层问题会掩盖下层。** 越层调优等于在错误的地基上装修。

举例：如果 SQP 显示你的**点击份额低于曝光份额**（买家看得到但不点），
那你再怎么调出价都只是把钱烧在点不动的流量上 —— 这时候你该去改主图和价格，不是改广告。

### 4.2 九层清单

| 层 | 看什么 | 关键动作 |
|---|---|---|
| **第 0 层 份额漏斗（SQP）** | 曝光/点击/加购/购买四个份额 | **先判断"该不该调广告"** |
| 第 1 层 店铺/账户 | TACoS 趋势、广告占比、是否蚕食自然位 | 决定收还是放 |
| 第 2 层 广告活动 | 预算是否烧穿、ACoS vs 目标、曝光份额 | 预算与出价大方向 |
| 第 3 层 广告组/关键词 | 结构是否混杂、匹配方式是否打架 | 拆组、收敛 |
| 第 4 层 搜索词 | 收割 / 否定 / 迁移 | **最高频、最见效** |
| 第 5 层 广告位 | TOS / ROS / PP | 加价或收紧 |
| 第 6 层 时段 | 高低峰表现差异 | 预算节奏 |
| 第 7 层 大促期指标解读 | CTR↓ + CVR↑ 是否正常 | 避免误判 |
| 第 8 层 新增需求分析 | 新词 vs 历史词 | 发现增量机会 |

### 4.3 第 0 层的意义（最容易被忽略）

**它决定「该不该调广告」。**

用 Brand Analytics 的搜索查询绩效（SQP）看品牌四份额
（曝光 → 点击 → 加购 → 购买），找**相邻两环节落差最大**的那处：

| 断崖位置 | 病因 | **不要做什么** |
|---|---|---|
| 点击份额 < 曝光份额 | 主图/价格/评分/标题 | ❌ **不要加价**（加价只是把更多钱烧在点不动的流量上） |
| 加购份额 < 点击份额 | 详情页/卖点/图文 | ❌ **不要扩量** |
| 购买份额 < 加购份额 | 价格/运费/优惠券/库存 | ❌ **不要怪广告** |
| 曝光份额极低 + 全站搜索量大 | 没抢到曝光 | ✅ 进入第 2 层，加价 + 加预算 |

**口诀：份额落差在哪一环，钱就不该花在广告上，而该花在那一环。**

**这个判断有独立来源佐证**（中文实战文 FAQ 原话）：
> 「**竞价只能影响广告竞争与点击成本**。流量不相关、售价变化、库存紧张或页面无法承接时，
> 单独调价通常无法解决转化问题。」

**前置条件**：SQP 需品牌备案。无备案则跳过本层，但要意识到"转化问题 vs 投放问题"的区分能力会下降。

### 4.4 第 1 层：店铺/账户

| 信号 | 判断 | 动作 |
|---|---|---|
| TACoS 连涨 3 周，总单量不涨 | 广告在蚕食自然位 | 收非核心活动预算 |
| TACoS 涨但自然单占比同步涨 | 正常投资期 | 不动，继续观察排名 |
| 广告花费占比 > 40% 且利润下滑 | 结构失衡 | 重算目标 ACoS，砍结构性亏损活动 |

**证据要求**：至少 3 周数据。单周 TACoS 波动不构成判断。

### 4.5 第 2 层：广告活动

| 信号 | 阈值（起点） | 动作 |
|---|---|---|
| 预算提前烧完 + ACoS ≤ 目标 | — | 提预算 20%~30%，一周后看 |
| 预算提前烧完 + ACoS > 盈亏线 | — | **先降出价/加否词，禁止加预算** |
| ACoS > 盈亏线 且点击 ≥ 20 | — | 降价 20%~30%，观察一个周期 |
| ACoS 在目标与盈亏线之间 | — | 降价 10%~15% 微调 |
| ACoS ≤ 目标 × 0.8 且预算受限 | — | 加预算 + 逐步提价 |
| 连续 14 天 0 单、花费 ≥ 10× 目标 CPC | — | 暂停并复盘（**不要直接删**，保留数据） |
| **新活动/大改后 < 3 天**（保守 7 天） | 学习期 | **不调出价、不调结构** |

> **学习期的机制**：独立来源指出「**频繁调整本身会重置/延长学习期**」——
> 不只是"前几天没数据"，而是你的每次改动都在让系统重新学习。

### 4.6 第 3 层：广告组与关键词结构

| 信号 | 动作 |
|---|---|
| 单广告组关键词 > 50 个 | 按主题/匹配方式拆组 |
| 同一广告组混多个不相关品类 | 拆组，否则否定词互相打架 |
| **同组混不同价格区间的商品** | 拆组：高客单可出高价仍保 ROAS，低客单必须低价 |
| **同组混不同 ROAS 表现的商品** | 拆组，按转化率与价格分组 |
| 只剩 1 个在投商品 | 官方要求**至少投 2 个**推荐商品 |
| 同一关键词出现在 3+ 活动 | 收敛，避免自我竞争推高 CPC |
| Auto 与 Manual 抢同一个词 | 在 Auto 中**精确否定**该词，让流量归 Manual |
| 广泛匹配词表现好 | 订单 ≥ 2 且 ACoS ≤ 目标 → 迁 Exact，**原位置否定精确** |

**迁移黄金规则**：词往「更精确」的方向走（Auto → Broad → Exact），**旧位置必须否定精确**，
否则两边继续抢量、CPC 被自己抬高。

### 4.7 第 7 层：大促期的指标反向解读

**大促期 CTR 下降 + CVR 上升是正常现象，不是效率下降。**

实测（某次 Prime Day，单一来源）：CTR **−12.3%**，CVR **+6.2%**。

原因：大促期所有卖家抢曝光，消费者被广告轰炸后点击更谨慎；但真正点进来的人购买意图更强。

| 大促期现象 | 错误反应 | 正确判断 |
|---|---|---|
| CTR 下降 | 改主图/降出价 | 看 CVR 是否同步上升 |
| ACoS 上升 + CVR 上升 | 全面降价 | 区分「竞争推高 CPC」与「流量变差」 |
| ACoS 上升 + CVR 下降 | 加预算追量 | 是流量真的变差，要收 |
| 花费提前烧完 | 直接加预算 | 先看是否错配了时段 |

**大促期真正该看的不是单个指标涨跌，而是「预算有没有流向更高价值的流量」。**

## 第 5 章 搜索词报告怎么读

### 5.1 关键词 vs 搜索词

| | 定义 |
|---|---|
| **关键词** | **你主动设置**的投放对象 |
| **搜索词** | **消费者实际输入**并触发广告的查询 |

**例子**：你投了一个宽泛的产品词，消费者可能用更具体的规格词、场景词触发广告，
也可能带来一个看起来相似、实际购买意图差很多的搜索词。

**所以广告运行后，搜索词往往比单看关键词更有用。**

### 5.2 搜索词层的三个动作

#### 动作一：收割（转 Exact）

**判据是「转化速率」，不是 ACoS。**

```
转化速率 = 订单 ÷ 运行天数 × 7
```

| 速率 | 动作 |
|---|---|
| < 1 单/周 | 不收割，留在发现活动里 |
| 1~2 单/周 | 加到 **stacked Exact** |
| **≥ 2 单/周** | 给**独立单关键词 Exact 活动** |

**为什么不用 ACoS 当闸门** —— 独立来源原话：
> *"don't use ACoS and margin to decide **whether** to harvest.
> A term that converts reliably at a bad ACoS is exactly the term that most needs its own campaign
> — because right now you can't do anything about the bid."*

**逻辑**：独立活动是你**唯一能改出价的前提**。用 ACoS 当闸门会把最需要救的词挡在外面。

**收割的完整闭环（两步，缺一半就没做完）**：
1. **广告侧**：加入手动广告单独投放
2. **自然侧**：**埋入 Search Term 与五点描述** ← 让自然流量也吃到这个词

> 只做第 1 步的话，你仍然在**为这个词持续付费**。

**优质词标准**：高点击 + 高转化 + 低 ACoS + 低 CPC 均价（**四条件同时满足**）

#### 动作二：否定

**否定判定的三个必须同时满足的条件**：

1. **数字达标** —— 点击 ≥ `1 ÷ CVR`（重点排查线约 2.5~3 倍）
2. **词义不匹配** —— 搜索需求与商品**确实无法匹配**
3. **连续观察** —— 无效点击在**连续观察期**内持续出现，不是某一天的波动

> 独立来源原话：「**一个词短期没有订单，无法单独证明它应该被否定**。」
> **只满足第 1 条就否词，是最常见的误伤来源。**

**否定方式选择**：
- 单个无关词 → 否定**精确**
- 一类无关词根（竞品品牌、错误品类）→ 否定**词组**
- 已在别处出单的词 → 否定精确（**用于隔离，不是淘汰**）

**通用浪费修饰词种子表**（建活动前预先否定，省掉前期浪费）：

| 类型 | 词例 | 方式 |
|---|---|---|
| 免费/低价 | free, cheap, cheapest, budget | 词组 |
| 二手/维修 | used, refurbished, repair, broken | 词组 |
| 教程/资讯 | how to, tutorial, DIY, review, reddit, wiki | 词组 |
| 错误品类 | 与本品共享词根但不同类 | 词组 |
| 竞品品牌 | — | **谨慎**：取决于是否要做竞品词截流 |

> ⚠️ 否定词不是越多越好。误否会切断有效流量 ——
> 尤其「教程/资讯」类词在部分类目（工具、配件）反而是高转化意图。
> **先小批量否定，观察曝光变化再决定是否扩大。**

#### 动作三：降价

| 信号 | 动作 |
|---|---|
| ACoS > 盈亏线 且点击 ≥ 20 | 降价 20%~30% |
| ACoS 在目标与盈亏线之间 | 降价 10%~15% |
| CTR 低（经验起点 0.2%）且曝光充足 | 问题在主图/价格/相关性，**不是出价** |

**分档降价规则**（**单一来源，未交叉验证**）：

| 当前 ACoS | 动作 |
|---|---|
| > 200% | 降价 30%~50% |
| 100%~199% | 降价 20% |
| 目标 +10%~99% | 降价 10%~15% |
| 目标 ±10% | **不动** |
| 低于目标 | 提价 10%~20% |

> **注意**：若已算出盈亏平衡线，**盈亏平衡线优先于本表**。
> 例：目标 25% 但盈亏线 22% 时，ACoS 30% 虽落在「目标+10%~99%」区间，实际已越线，应按止血处理。

### 5.3 点击没有订单时的 5 项前置核对

**先核对，再决定是否否定：**

1. 搜索词和商品是否**真的相关**？
2. 商品价格、库存、促销或详情页**是否在观察期间发生变化**？
3. 点击量与花费**是否已积累到足够判断**的程度？
4. 这个搜索词是否**已在其他广告组重复投放**？
5. **同类词的表现是否也出现了类似情况**？

### 5.4 数据量前置（不足就不要下结论）

- 「一天十几个点击、没有订单，**只能说明暂时没出单，还不足以下结论**」
- 复盘**至少拉 7 天**；遇大促、断货、售价调整、优惠券到期、配送时效变化 → **拉长到 14 天**

**日常诊断固定看四类数据**：

| # | 数据 | 看什么 |
|---|---|---|
| 1 | 广告搜索词报告 | 实际匹配到哪些词，及其点击/花费/订单/销售额 |
| 2 | 广告表现数据 | **分自动/广泛/词组/精准/商品投放分别看**，不要混在一起 |
| 3 | **业务报告** | **Sessions** 与 **Unit Session Percentage**（判流量问题 vs Listing 问题的关键） |
| 4 | 商品经营信息 | 售价、优惠券、评分、评论数、库存、配送、购物车、变体 |

## 第 6 章 广告位怎么读

### 6.1 三个位置

| 位置 | 特征 |
|---|---|
| **Top of Search（TOS）** | 搜索结果顶部。流量质量最高，CPC 也最高 |
| **Product Pages（PP）** | 商品详情页。竞品页/关联位 |
| **Rest of Search（ROS）** | 搜索结果其余位置。意图最弱 |

### 6.2 判定口径：看 ACoS 相对盈亏平衡线的倍数

**不要按 CVR 倍数判，要按 ACoS 相对盈亏平衡线的倍数判。**

| 广告位 | 高于即降 | 低于即加 |
|---|---|---|
| **Top of Search** | **1.15 × 盈亏线** | **0.7 × 盈亏线** |
| **Rest of Search** | **1.0 × 盈亏线** | **0.7 × 盈亏线** |
| **Product Pages** | **1.4 × 盈亏线** | **无加价档** |

**为什么 TOS 允许高于盈亏线**：这里买的是**排名与最优质的购物者**，不只是单次成交。
**为什么 ROS 严格卡在盈亏线**：它是意图最弱的位置，也**不带来排名**。
**为什么 PP 容忍带最宽**：一个真正跑通的商品页广告价值很高。

### 6.3 三条容易搞错的地方

**① 没有「Product Pages 加价」这回事**

独立来源原话：
> *"There is no **"Product Pages boost"** in any sensible ruleset either - on that surface
> you only ever want to be pulling back."*

商品页位的正确动作只有「收紧」。**（我们原本写过"PP ACoS 低 → 提高 PP 加价"，已被验证推翻。）**

**② 没有负修饰符**

想降低 PP 曝光的唯一办法是**提高 TOS / ROS 的加价**，或**降基础出价**。

**③ 降基础出价会同时削弱所有位**

包括本来跑得好的那个。正确做法：降基础出价 15% 时，
把高效位的修饰符**同步抬高以维持其有效出价不变**（例：原 50% 修饰符需提到约 76%）。

### 6.4 幅度纪律

**一次最多移动「当前值的 25%」，不是 25 个百分点。**

例：当前 33% → 最多动到 41% 或 25%。

**观察 14~30 天再动下一档。** 广告位加价上限 900%，但没有负值。

### 6.5 加价的反向约束

> 「一个广告位**展示很多，或点击很多，都不足以单独支持提高溢价**」
> —— 必须同时看到该位带来的**订单与销售额**。

**仅凭曝光/点击量加价是最常见的浪费来源。**

### 6.6 常用组合策略

**低基础出价 + TOS 高比例加价** —— 用低基础价压低 PP/ROS 的无效曝光，
同时用 TOS 高加价抢住高质量位置。

这正是「降基础出价会削弱所有位」的解法原型。
加价幅度按「与目标的差距」**动态**确定：差距大就多加，差距小就少加。

## 第 7 章 区分流量问题 vs Listing 问题

**新手最容易搞错的地方** —— 该否词时去改图片，该改图时又去扩词，忙一周花费没少订单没来。

### 7.1 先拆买家路径

```
买家搜索一个词 → 看到广告 → 点击进入详情页 → 比较产品/评分/配送/优惠 → 决定是否下单
```

**任何一个环节出问题，都可能出现"有点击、没订单"。要做的，是找到买家在哪一步离开。**

### 7.2 两层对比法

**第一层：横向比流量**（同时间段内比搜索词）

把**高点击、低订单**的搜索词挑出来，和**能稳定出单**的词放在一起对比：
搜索意图、匹配方式、广告位置、投放类型。

> **判据**：如果「精准核心词有订单，但自动/广泛匹配持续拿到大量高点击零订单词」
> → **问题在流量筛选**，不是 Listing。

**第二层：纵向比 ASIN 整体转化**

看**业务报告里的 Unit Session Percentage（单品转化率）**是否稳定：

| 广告转化 | 自然流量转化 | 判断 | 动作 |
|---|---|---|---|
| 差 | **稳定/正常** | **广告流量质量问题** | 查搜索词与投放目标，收紧匹配 |
| 差 | **同时下降** | **Listing / 商品条件问题** | 查主图、价格、库存、配送、评价、变体 |
| 好 | 稳定 | 健康 | 按正常放量逻辑 |

> **核心洞察**：用「**自然流量能不能买**」来反推 ——
> 自然来的买家能买、广告带来的不买，那问题在流量，不在页面。

### 7.3 CTR / CVR 组合判读（辅助参考）

**阈值均为经验起点，未获多源验证，仅供起步。**

| CTR | CVR | 判断 | 动作 |
|---|---|---|---|
| 低 | 低 | 曝光吸引力不足 + 转化也差 | 查主图/价格/相关性；暂不加价 |
| **高**（>0.5%） | **低**（<5%） | **Listing 问题** —— 点得进来说明主图没问题，是详情页留不住 | **不要动出价**，修 Listing |
| 低 | 高 | 曝光位或人群不匹配 | 查投放位置与匹配方式 |
| 高 | 高 | 健康 | 可加价放量 |

### 7.4 SQP 的加购环节：为什么会分不清

**广告报表里没有「加购」这一环** —— 而它恰好能把两类问题分开：

- 点击了但**没加购** → 详情页/卖点问题
- 加购了但**没买** → 价格/运费/促销问题

**没有这一环，这两类问题都会被误判成"广告效率差"，然后不断加价。**

## 第 8 章 动作库与风险分级

### 8.1 四级分类

| 级别 | 动作 | 执行方式 |
|---|---|---|
| **只读** | 查数、诊断、生成方案 | 直接做，无需确认 |
| **低风险写** | 加否定词、暂停单个明确亏损词 | 说明依据后执行 |
| **中风险写** | 改出价（±30% 内）、改广告位加价一档、加预算 ≤30% | **必须逐条确认** |
| **高风险写** | 建/删活动、改匹配方式、批量改 >20%、关整个活动、改预算 >30% | **必须逐条确认 + 影响预估 + 回滚方案** |

**默认行为**：只出方案不落盘。用户明确说「直接改」才进入写流程。

### 8.2 标准动作库

**出价类**

| 动作 | 触发 | 幅度 |
|---|---|---|
| 降价 | ACoS > 盈亏线，点击 ≥ 20 | −20%~−30% |
| 微调降价 | ACoS 在目标与盈亏线之间 | −10%~−15% |
| 提价 | ACoS ≤ 目标 × 0.8 且曝光受限 | +10%~+20% |
| 抢位置提价 | TOS 转化显著更优 | +25% 一档 |

**否定类**：见第 5 章（三条件 + 精确/词组选择）

**结构类**

| 动作 | 触发 |
|---|---|
| 建 Exact 活动/组 | 搜索词**转化速率** ≥ 1~2 单/周 |
| 原位置否定精确 | 完成迁移后**必做** |
| 拆广告组 | 单组关键词 > 50 或主题混杂 |
| 收敛重复词 | 同一词出现在 3+ 活动 |

**迁移出价起手**：新建 Exact 的初始出价按**当前自动活动出价的 80%** 起步，
再用 `可接受 CPC` 复核上限。

**状态类**

| 动作 | 说明 |
|---|---|
| 暂停 | 用于止血；**数据保留，可恢复** |
| 归档/删除 | 仅在确认无历史价值时；**删除不可逆** |
| **不要频繁启停** | 反复开关会打断学习期 |

### 8.3 限速规则（防止把账户玩坏）

1. **单次批量变更 ≤ 该对象总量的 20%**（如 100 个词一次最多改 20 个）
2. **学习期内（新建或大改后 < 3 天，保守 7 天）不做出价或结构变更**
3. **同一对象的两次出价调整间隔 ≥ 3 天**；实操观察期 **3~5 天**
4. **广告位加价一次只动一档**，观察一个完整周期再动下一档
5. **大促前 14 天 / 大促当天不做结构性调整**
6. **库存 < 30 天销量时暂停加投类动作**

### 8.4 变更留痕与回滚

**每次写操作前记录**：

```
时间 / 对象（名称+ID）/ 字段 / 改前值 / 改后值 / 依据 / 预期影响 / 回滚条件
```

**回滚触发条件要写具体到数字**：

- 3 天后 ACoS 未改善且订单量下降 > 20% → 回滚出价
- 提预算后 3 天 CVR 未变 → 回滚预算
- 否定后曝光下降 > 40% → 检查是否误否

> **没有改前值，就不要执行写操作。** 拿不到改前值的批量工具不要用。

### 8.5 执行前检查清单

- [ ] 目标明确（利润 / 排名 / 清库 / 冲量）
- [ ] 盈亏平衡 ACoS 与目标 ACoS 已算出
- [ ] **份额短板已定位**（有 SQP 时先跑第 0 层）
- [ ] 数据时间窗与币种已标注
- [ ] 不在学习期 / 不在大促 / 库存充足
- [ ] 变更清单已给用户看过，**含改前值**
- [ ] 批量变更比例 ≤ 20%
- [ ] 回滚条件已写明

## 第 9 章 阈值从哪来、怎么判断可信度

> **这一章的目的不是背阈值，是学会「怎么判断一个说法该不该信」。**
> 阈值会随类目和平台变化，判断信息可靠性的能力不会。

### 9.1 三级证据

看到任何一条投放"知识"，先分类：

| 级别 | 含义 | 例 |
|---|---|---|
| **官方口径** | Amazon 官方文档明确写的 | 盈亏平衡 ACoS 与利润边际的挂钩关系 |
| **多源验证** | ≥2 个**独立**来源（不是互相转载） | 可接受 CPC = 售价 × CVR × 目标 ACoS（两个独立实现给出逐字相同公式） |
| **经验起点** | 单一来源或无来源 | CTR < 0.2% → 主图问题 |

**判据的独立性**：同一内容的镜像/转载**不算独立来源**。
例：某开源 Skill 是另一个 Skill 的分发版，只计一次。

### 9.2 三个必须问的问题

1. 这是**官方口径**、**多源验证**，还是**个人经验**？
2. 它的**适用范围**是什么？（类目 / 客单价 / 阶段）
3. 有没有**反例**？

### 9.3 优先接受「可推导的规则」，而不是「固定魔数」

| 魔数 | 可推导的规则 |
|---|---|
| 「点击 15 次没单就否定」 | **`1 ÷ CVR`**（CVR 8% → 约 12~13 次） |
| 「ACoS > 40% 就降价」 | **`ACoS > 1.15 × 盈亏平衡线`** |
| 「日预算设 $20」 | **`(1 ÷ CVR) × CPC`** |

**为什么**：魔数在换产品/换类目/换站点后失效，而可推导的规则跟着参数走。

### 9.4 我们实际推翻过哪些流传很广的说法

| 被推翻的 | 为什么 | 改后 |
|---|---|---|
| **Product Pages ACoS 低 → 加 PP 价** | 独立实现原话：*There is no "Product Pages boost" in any sensible ruleset* | 按 ACoS 相对盈亏线的倍数判定，PP **只有收紧档** |
| **收割 = 订单 ≥2 且 ACoS ≤ 目标** | ACoS 差但稳定转化的词，恰恰最需要独立活动来调出价 | 改为**转化速率**制 |
| **时段低迷 → 暂停投放** | 暂停破坏连续性、降低广告权重与质量得分 | 改为**降预算与出价，不暂停** |
| **否定阈值固定 10 次** | 独立来源：*"it's wrong for most products"* | 改为 **`1 ÷ CVR`**（下限 5） |

### 9.5 一条判断经验（很值钱）

> **当模型/影子层与规则层大面积不一致时，先怀疑设计，而不是庆祝发现了分歧。**

实测：第一版影子层对 12 个词里的 **10 个**都判"暂停"，分歧率 **91.7%**，连 ACoS 26% 的健康词也是。

**信号**：输出分布**比规则层更极端、更单一** + 置信度区间很窄 → 几乎一定是设计问题。

**根因**是没在指令里写清判断口径 —— 模型不知道什么时候该选哪个动作，退化成最保守选项。
补上口径后，分歧率降到 **33.3%**，自动执行从 1 升到 7。

## 第 10 章 八个场景

> **同一个 ACoS，目标不同结论完全相反。** 先认场景，再套规则。

### 场景 A：新品冷启动（0~60 天）

**目标**：拿到初始订单与评论，把核心词自然排名推起来。**不是赚钱。**

**结构建议**
1. **Auto**（1 个）：跑词、跑 ASIN —— 只用来「发现」，不用来「收钱」
2. **Manual 广泛/词组**（1~2 个）：核心词 5~10 个，按主题分组
3. **Manual 精确**（少量）：只放已验证的高相关词
4. **商品定位（ASIN 定投）**：竞品页 + 类目页，单独活动便于控预算
5. SB/SD：有品牌备案再上，新品期可先不开

**出价策略**
- 起始出价 = 可接受 CPC × 1.2（新品转化率未知，先给一点溢价抢曝光）
- 核心词用固定竞价起步，别一上来用「仅降低」，否则抢不到位置
- 前 14 天允许 ACoS 高于盈亏线，**但要有预算上限**（按能承受的总亏损倒推日预算）

**节奏**

| 时间 | 动作 |
|---|---|
| 第 1~7 天 | 只看数据，不动出价（学习期）。检查有无跑偏词 |
| 第 8~14 天 | 首轮否定词、收割首批出单词 |
| 第 15~30 天 | 出价下调到目标区间、扩充 Exact |
| 第 31~60 天 | 结构收敛，ACoS 向目标收敛；开始 TACoS 考核 |

**官方口径补充**：
- **活动不设结束日期**（always-on）
- **至少投 2 个推荐商品**
- **预算双向调**：常烧穿 → 加预算；预算过剩 → 降预算挪给其他活动
- 用手动活动**补充**自动活动（不是替代）

**验收指标**：自然搜索排名、自然订单占比、评论数增长 —— **而不是 ACoS**。

### 场景 B：成熟品提效

**目标**：把 ACoS 压向目标值，同时保住自然排名。

**动作顺序**
1. 砍结构性亏损：ACoS > 盈亏线的词/活动，先降价再加否词
2. 收割：把出单词全部收进 Exact，删除重复覆盖
3. 广告位精细化：按边际效率调 TOS / PP
4. 预算重分配：从低效活动搬到高效活动（一次 ≤ 20%）
5. 最后才考虑收总量：优先「减少浪费」而不是「减少曝光」

**红线**：不要为了报表好看把广告全关。广告掉量 → 自然排名掉 → 总利润反而下降。

### 场景 C：旺季 / 大促

**提前 3~4 周**
- 广告位加价前置调高（TOS），大促期间 TOS 竞争最激烈
- 预算按去年同期 × 1.3~1.5 预置，**大促当天不要中途砍预算**
- 大促前 2 周**不要做结构性大幅调整**（避免学习期撞上大促）

**大促期间**
- 数据当天不可比，**不要用大促数据做日常决策**
- 关注预算烧穿时点，及时加预算（宁可多花，不要中午断流）

**大促后**
- 一周后再做结构判断；把大促期间的高效词沉淀进 Exact
- 预算回落到日常水位

### 场景 D：清库存 / 断码

**目标**：周转，不是利润。**ACoS 可以高于盈亏线。**

- 放宽到「只算现金回收」，可接受亏损上限 = 单件沉没成本
- 重点投：清仓词、竞品 ASIN 定投、SD 再营销
- 不要投：长期品牌词（浪费）、高竞争大词（贵）
- **库存 < 30 天销量时停止加投**

### 场景 E：防守竞品 / 品牌保护

- **品牌词必须投**，且要买到 TOS（防守竞品在你的品牌词上截流）
- 品牌词 ACoS 通常最低，**别把它砍掉**
- **竞品词**单独活动，低预算高监控
- **ASIN 定投**针对竞品详情页，独立活动便于按竞品单独控预算

### 场景 F：多站点

- 每个站点**独立**算盈亏平衡 ACoS（币种、佣金、VAT、FBA 费、退货率都不同）
- **不要用美国站的目标 ACoS 去要求欧洲站**
- 汇率波动大的时期，目标 ACoS 要留缓冲
- 小站点预算小 → 优先 Exact 与品牌词，别开 Auto 烧预算

### 场景 G：季节性产品

| 阶段 | 提前量 | 动作 |
|---|---|---|
| **旺季前** | 4~6 周 | 加预算、提 TOS 加价、核心词出价拉到竞争位。**允许 ACoS 高于目标** |
| 旺季前 2 周 | — | **停止结构性调整**（拆组/换词/改匹配） |
| 旺季中 | 当周 | 保预算不断流；用否定词挡低意图流量 |
| 旺季尾 | 结束前 3~5 天 | 逐步回收加价与预算，**不要断崖式关停** |
| 旺季后 1~2 周 | — | 专项复盘，高效词沉淀进 Exact |

**关键判断**：季节性产品的广告效率**只能用同比看，不能用环比** ——
淡季 ACoS 天然比旺季高，**拿淡季数据砍旺季预算是最常见的错误。**

### 场景 H：即将断货 / 已断货 / 恢复上架

**这是最容易亏钱的场景** —— 广告把流量打进来却发不出货，等于花钱买差评。

| 状态 | 库存 | 广告动作 |
|---|---|---|
| **警戒** | 可售天数 < 30 天 | **停止所有加投类动作**；只做止损类优化 |
| **收缩** | < 14 天 | 逐步降出价、降预算，让流量平滑下滑（**不要直接关活动**） |
| **断货前** | < 7 天 | 关掉 Auto 与广泛匹配，只留品牌词与 Exact 维持基本曝光 |
| **断货中** | 0 库存 | 保留品牌词与核心 Exact 低预算投放（维持关键词权重与自然位） |
| **恢复上架** | 补货到仓 | 先小预算重启，逐周恢复；**不要一次恢复到断货前预算** |

**两条硬规则**
1. **绝不在库存不足时加投** —— 断货比少卖更伤排名与评论
2. **断货后不要指望广告把排名买回来** —— 先靠转化与评论恢复自然位，广告只做辅助

### 场景速查

| 问题 | 先看 | 先别做 |
|---|---|---|
| 新品没订单 | 曝光够不够 → 转化率 | 猛加出价 |
| 老品 ACoS 涨 | 搜索词层（是否跑偏） | 直接砍预算 |
| 花费高没单 | 搜索词报告（找浪费词） | 关活动 |
| 有单没利润 | 重算盈亏线（费用是否漏算） | 继续放量 |
| 大促后下滑 | 预算是否未回落 | 加投追量 |
| 自然单掉了 | 广告单占比（是否蚕食） | 关广告 |

## 第 11 章 报告体系

**核心纪律：不要每天都做全量诊断。节奏错了比不做更糟。**

### 11.1 三种节奏

| 周期 | 看什么 | **不做什么** |
|---|---|---|
| **每日** | 预算烧穿、异常花费、跑飞的词 | **不要因单日波动调出价** |
| **每周** | 搜索词收割/否定、出价调整、广告位 | 不要每周改结构 |
| **每两周** | 广告组与匹配方式结构、预算分配 | 不要频繁重启活动（打断学习期） |
| **每月** | TACoS 与利润、ACoS 目标校准、旺季预算 | — |
| **大促后 1~2 周** | 专项复盘 | **不要跳过复盘就"恢复日常广告"** |

### 11.2 日报（只做异常监控，5 分钟看完）

```
【异常告警】
- 预算烧穿：<活动名> 在 <时间> 前花完
- 花费异常：<活动名> 单日花费为 7 日均值的 N 倍
- 跑飞词：<搜索词> 今日点击 N、0 单，花费 $X
- 断流：<活动名> 曝光为 0
- 库存告警：<ASIN> 可售天数 < 30
```

**日报纪律**：只处理**明显异常**，其余留给周报。

### 11.3 周报（主要工作产出）

必须包含五节：

1. **核心指标**：花费 / 广告销售额 / ACoS / 总销售额 / TACoS / 广告单占比（本周 vs 上周 vs 目标）
2. **分层诊断**：店铺层 → 活动层 → 搜索词层 → 广告位层
3. **本周动作清单**：**必须含改前值**
4. **★ 上周动作复盘**：预期 vs 实际 vs 结论（有效 / 无效 / 待观察）
5. **下周计划**：只列 3~5 条，聚焦

> **第 4 节是区分专业与业余的地方。没有复盘，优化就是随机游走。**

### 11.4 月度复盘

1. 结果：总销售额 / 广告花费 / TACoS / 净利润 / 广告单占比趋势
2. **目标校准**：盈亏平衡 ACoS 是否变化？（成本、FBA 费、佣金、退货率、汇率）
3. 结构性结论：哪些活动类型是净贡献？预算分配是否该调整？
4. 下月重点：最多 3 条
5. 需要老板/供应链决策的事：定价、库存、新品、断货风险

### 11.5 汇报口径纪律

| 纪律 | 说明 |
|---|---|
| 每个数字带时间窗 | 「ACoS 32%」无效，「近 14 天 ACoS 32%」有效 |
| 带币种与站点 | 跨站点不给单一 ACoS |
| **区分事实与推断** | 推断要写假设 |
| 不藏坏消息 | ACoS 超标就写超标 |
| **不承诺精确预测** | 用「预期区间」而不是「一定降到 X%」 |
| 数据不全就标注 | 写明缺哪张报表、影响哪些结论 |

## 第 12 章 大促复盘

### 12.1 复盘的立场（先纠正目的）

**大促复盘的目的不是总结过去赚了多少，而是回答：消费者到底告诉了你什么？**

- ❌ 错误起手式：打开后台看销售额/ACoS/花费，然后「恢复日常广告」
- ✅ 正确起手式：先问「这次大促，**验证了什么**？」

**判断标准**：如果复盘的结论落不到「下一轮预算怎么配置」，它就只是统计，没有产生经营价值。

大促把平时需要两三个月才能积累的样本压进四天 —— 它是**消费者集中表达需求的机会**。

### 12.2 三维度九问框架

| 层 | 问题 |
|---|---|
| **整体表现** | ① 广告整体效率提升还是下降？② 流量结构发生了什么变化？ |
| **流量来源** | ③ 哪些搜索词真正贡献了订单？④ 有多少是**第一次成交的新词**？⑤ 这些新词是偶然还是长期机会？ |
| **时间与结构** | ⑥ 哪几个小时最值得投入预算？⑦ 不同匹配方式发生了什么变化？⑧ Auto 有没有发现新机会？⑨ 下一次大促，预算应该怎么分配？ |

### 12.3 搜索词层：找「新增需求」

**必算两个数**：

```
新出单词占比 = 本期新出单词数 ÷ 本期全部出单词数
新词效率倍数 = 新词 CVR ÷ 历史词 CVR
```

| 信号 | 判断 | 动作 |
|---|---|---|
| 新出单词占比高（如 > 30%） | 需求正在扩张，Auto 探索有效 | 保留 Auto，加速收割新词 |
| 新词 CVR > 历史词且 ACoS 低 | 存在未被满足的明确需求 | **迁 Exact，重配预算** |
| 新词集中在长尾（≥ 3~6 词） | 消费者表达更具体 | 长尾单独建组，别混进大词 |
| 历史出单词在大促期 0 单 | 竞品动作/排名下滑的早期信号 | **进「观察名单」** |

> **原则**：高转化低 ACoS 的词往往不是流量最大的核心词，而是需求表达明确的长尾词。
> **不要让已验证的好词继续留在 Auto** —— Auto 的价值是发现需求，不是长期贡献订单。

### 12.4 ★ 自然权重验证法（很实用）

大促后最该做的事：**把广告目标从「冲排名」改为「验证自然权重」**。

| 动作 | 观察 | 结论 |
|---|---|---|
| **关掉广告** | 排名掉了 | **结构不稳定**，自然权重还没接住，仍需广告维持 |
| **降低广告** | 排名与单量仍稳住 | **自然权重已形成**，可以逐步降预算 |

**执行节奏**：**活动结束后第 3 天开始，用 3~5 天逐步降预算**（**不要一次性关停**），
观察**自然单占比**与**核心词排名**的变化。

> 正向信号：**降预算后自然单占比反而上升** → 链接已经站稳。

### 12.5 大促后的结构重组

**先认清「销量是租来的」** —— 大促销量由三类流量构成，共同点是来得快走得也快：
活动流量、低价冲动流量、临时关键词爆发流量。

**流量结构三分类**：

| 结构 | 特征 | 补货 | 广告 |
|---|---|---|---|
| **稳定型** | 主词持续进流 + 长尾词占比提升 + **非活动词占比 > 60%** | 正常节奏 | 可放量 |
| **波动型** | 主词还在但下降 + 长尾词减少 | 按正常需求的 **70%~80%** | 控制预算，防守为主 |
| **脉冲型** | 流量高度集中活动词 + 新增自然词极少 | **只维持安全库存** | 只保留防守型低价投放 |

**大促后的防守型结构比例（经验起点）**：**30% 核心词 / 50% 长尾词 / 20% 防守词**

### 12.6 复盘后立刻做的五件事

| # | 动作 | 触发条件 |
|---|---|---|
| ① | **加词**：迁移到 Exact | ACoS < 20% 且出单 ≥ 2 的新搜索词 |
| ② | **建观察名单**：监控大促期间消失的历史出单词 | 历史出单词大促期 0 单 |
| ③ | **收窄 Phrase**：加否定或迁 Exact | Phrase 效率下降 |
| ④ | **保留 Auto** | 无条件 —— 它是后续扩量的来源 |
| ⑤ | **调整预算节奏**：把高效时段写进 SOP | 有时段集中证据时 |

### 12.7 分时（dayparting）

| 来源 | 窗口 | 幅度 |
|---|---|---|
| 中文实战 | 16:00–21:00（订单连续 5 小时增长 >100%） | 提价 20%~30%，集中 40%~50% 预算 |
| 英文独立实现 | Mon–Fri 18:00–23:00 | 提价 25%，窗口外自动恢复 |

**两个独立来源的窗口落在同一时段带（傍晚到夜间）、幅度量级一致（20–30%）。**

**关键认知（修正过我方原写法）**：

> ⚠️ **不要用「暂停投放」来做分时。**
> 独立来源原话：暂停广告「**破坏了广告的连续性，从而造成广告权重在无形中降低，
> 进而引起广告质量得分下降**，要维持原来的广告位置就得出更高的价格，并不划算」。
> **正确做法是在高低峰时段设置不同预算与出价。**

**⚠️ 分时工具的运行风险**：如果调度在**窗口结束时没跑起来**，
**提高后的出价会一直保持下去**，没人发现就一直按溢价买 24 小时的量。
上线前必须确认工具有「窗口结束自动恢复原出价」机制。

## 第 13 章 份额视角（SQP）

> 需要**品牌备案**。没有的话这一章可以先跳过，但要知道自己缺了什么能力。

### 13.1 为什么必须加这一层

| 报表 | 能回答 | 答不了 |
|---|---|---|
| 广告搜索词报告 | 钱花在哪、出多少单、ACoS 多少 | 我**占多少份额**、短板在漏斗哪一环、自然位有没有起作用 |
| **SQP** | **份额构成 + 全链路漏斗 + 自然/广告同框** | 具体某次点击的出价与花费 |

**关键差异**：广告报表是「我的支出视角」，SQP 是「市场份额视角」。

**只看广告报表，你会把「转化问题」误当成「出价问题」—— 于是不断加价，越加越亏。**

SQP 给出的漏斗：

```
全站：搜索量 → 全站曝光 → 全站点击 → 全站加购 → 全站购买
品牌：        品牌曝光 → 品牌点击 → 品牌加购 → 品牌购买
份额：        曝光份额   点击份额   加购份额   购买份额
```

**注意「加购」这一环** —— 广告报表里完全没有，而它恰好能把「不想要」和「想买但没下单」分开。

### 13.2 份额断崖定位法

**做法**：把品牌四个份额按漏斗顺序排开，找**相邻两环节落差最大**的那一处。

| 断崖位置 | 病因 | **不要做什么** |
|---|---|---|
| 曝光份额本身就低 | 相关性弱/竞价不足/预算受限 | — |
| **点击份额 < 曝光份额** | 主图、价格、评分、标题、变体 | ❌ **不要加价**（加价只是把更多钱烧在点不动的流量上） |
| **加购份额 < 点击份额** | 详情页、A+、卖点表达、图文不符 | ❌ **不要加预算扩量** |
| **购买份额 < 加购份额** | 价格、运费、优惠券、库存、配送时效 | ❌ **不要怪广告** |
| 某环节份额反而高于全站 | 这是你的**优势环节** | 用于防守与放大 |

### 13.3 品牌 vs 全站的三组转化率对比

| 对比项 | 品牌 < 全站 | 品牌 > 全站 | 结论 |
|---|---|---|---|
| 点击率（点击/曝光） | 主图/价格/评分弱 | 有外观或价格优势 | 弱势优先修图与定价 |
| 加购率（加购/点击） | 详情页说服力弱 | 卖点表达有效 | 弱势优先修 A+ 与五点 |
| 购买转化率（购买/加购） | 临门一脚输 | 价格与信任感强 | 弱势优先修价格与促销 |

**用法**：**不要只看品牌自己的绝对值** —— 要与同一行里全站的值对比。全站值就是你所在类目的市场基准。

### 13.4 SQP → 投放动作映射

| SQP 信号 | 诊断 | 投放动作 |
|---|---|---|
| 曝光份额高 + 点击份额低 | 看得到不点 | **先修主图/价格/评分；广告不加价，可先降预算止血** |
| 点击份额高 + 加购份额低 | 点进来不想买 | 修详情页；维持出价不加，暂时不扩量 |
| 加购份额高 + 购买份额低 | 想买没下单 | 修价格/运费/优惠券；**广告降价或暂停，等转化修好再放** |
| 曝光份额极低 + 全站搜索量大 | 该抢但没抢 | **加价 + 加预算**，优先抢 TOS |
| 四份额均高 + 广告 ACoS 也低 | 统治该词 | **防守**：保持出价，预算保足 |
| 自然份额强但广告份额低 | 自然位已够 | **可省广告预算**，挪给弱势词 |
| 广告份额高但自然份额弱 | 靠广告撑 | 广告不能停；同时补自然排名 |
| 广告与自然份额高度重叠 + 总份额不涨 | 广告在蚕食自然 | 收广告预算或降 TOS 加价，看总份额是否维持 |

**顺序不能颠倒**：SQP 决定「**该不该在这个词上花钱、该先修什么**」，
ACoS / 可接受 CPC 决定「**花多少钱**」。

### 13.5 词簇法

**问题**：单看一个长尾词，点击量永远达不到统计显著（< 10 次点击），逐词优化等于对着噪声调参。

**做法**：按**词根 / 意图**把长尾词聚成簇，对**簇**做判断。

| 步骤 | 操作 |
|---|---|
| 1. 分词根 | 如 `portable blender` 簇内：`for smoothies` / `rechargeable` / `cup` |
| 2. 归簇 | 同一词根、同一购买意图的归为一簇 |
| 3. 看三个数 | **簇的自然排名**、**簇的自然流量占比**、**簇的整体订单净增量** |
| 4. 判断 | 整簇在涨 → 加大投入；整簇在跌 → 查是竞品还是季节 |

**与 SQP 的配合**：SQP 告诉你单词份额，词簇法解决「单词样本不足」——
两者叠加才既有精度又有统计量。

**簇级 KPI（不要逐词考核）**：簇曝光份额、簇自然排名中位数、簇自然订单占比、簇整体订单净增量。

## 第 14 章 什么时候不该相信模型

> 这一章不只是投放知识，是**「如何与 AI 协作做决策」的通用能力**。

### 14.1 模型能做决策的前提（三条同时满足）

1. **答案空间能提前穷举**（选项 / 是非 / 有序档位）
2. **是语义判断，不是算术**（算的在代码里算完再传）
3. **要高频重复跑**（否则普通 LLM 一次就够）

**广告关键词动作恰好三条都满足** —— 所以值得用；但边界多，**必须先标定**。

### 14.2 决策模型的三条硬边界

| # | 边界 | 对策 |
|---|---|---|
| 1 | **不是计算器，且不可靠计数**（误差随规模增长） | 所有比例/差值/天数**代码算好再传** |
| 2 | **上下文腐化**：无关内容会扭曲置信度 | **只给判断需要的字段**，不整表塞入 |
| 3 | **不用日期比较**（把日期当文本读） | 日期先转成日期类型 |
| 4 | **不生成文本** | 只做判断，不写文案 |

**实测证据**：同一判断，只是加入 26k tokens 的无关内容 ——
**清晰案子的置信度 +0.09（虚高）、模糊案子 −0.33（崩塌）**。

两种方向都在毁你的自动化率，而且**你看不出来**，因为置信度本身就是你以为用来判断"该不该信"的那个数。

### 14.3 置信度不可跨输入规模迁移

| 档位 | tokens | 清晰案例置信度 | 模糊案例置信度 |
|---|---|---|---|
| L0 只给所需字段 | ~630 | 0.57 | **0.85** |
| L4 +无关干扰 | ~26,200 | 0.66（**+0.09**） | 0.52（**−0.33**） |

**但选中的答案极稳**：state 放大 41 倍，**选中的动作 10/10 一次没变**。

**结论**：
- **用「选中的答案」做判断可靠**
- **用「置信度的绝对值」做门控不可靠 —— 除非在"你实际会发的输入形状"上重新标定**

### 14.4 正确的架构：规则层做主路径，模型做影子

```
规则层（可追溯）  → 主路径，出动作 + 依据
模型层（黑盒概率）→ 影子层，出第二意见
两者不一致        → 转为人工复核
```

**为什么不让模型做主路径**：
- 客户/老板问「为什么这个词要降价」，模型只能答「它给了 0.73」—— **无法复盘**
- 置信度没标定就不能做门控（见 14.3）

**影子的价值在「不同意」**：
> 规则层在边界上是硬的。ACoS 恰好是目标 1.1 倍时，规则会机械地说「微调降价 10%」。
> 模型给出独立第二意见。**两者不一致 = 这个案例确实模糊，正是最该让人看的地方。**

### 14.5 阈值标定的方法（必须做）

**没有标定就上模型 = 用一个已知会漂 ±0.33 的数做自动化门控。**

**步骤**：

1. 准备 **20~50 个真实样本**
2. 跑一遍，记录每个样本的「动作 + 置信度」
3. **扫多个阈值**（0.50 / 0.55 / … / 0.90），计算：
   - **覆盖率** = 判为「可自动」的比例
   - **一致率** = 在"可自动"子集里，模型与规则层判断相同的比例
4. 找**拐点**：覆盖率下降但一致率不再上升的那个阈值

**实测曲线示例**（45 个真实关键词）：

| 阈值 | 覆盖率 | auto 子集一致率 |
|---|---|---|
| 0.50 | 66.7% | 86.7% |
| 0.75 | 60.0% | 92.6% |
| **0.80** | **57.8%** | **96.2%** ← 拐点 |
| 0.90 | 55.6% | 96.0% |

**同时验证信号是否真有区分度**：

| 组 | 置信度均值 | 中位 |
|---|---|---|
| 与规则层一致 | **0.820** | 0.990 |
| 与规则层分歧 | **0.555** | 0.460 |

差 0.265（中位差 0.53）→ **confidence 确实能区分"同意"与"不同意"，信号不是噪声。**

### 14.6 ⚠️ 「一致率」不是「准确率」

**这是最容易自我欺骗的地方。**

没有人工标注时，只能用「与规则层是否一致」作为代理指标。
**但那些分歧里，规则层可能是错的** —— 这正是影子层存在的意义。

**要得到真正的准确率，必须人工逐条判定分歧案例。** 没有这一步，任何"准确率"都是自欺。

## 附录 C 核心公式一页速查

```
盈亏平衡 ACoS = (售价 − 成本 − FBA − 佣金 − 头程 − 退货损耗) ÷ 售价
目标 ACoS     = (单位贡献 − 目标净利) ÷ 售价
              = 盈亏平衡 ACoS × 策略乘数（launch 1.40 / grow 1.10 / dominate 1.15）
可接受 CPC    = 售价 × CVR × 目标 ACoS
点击阈值      = 1 ÷ CVR        （下限 5，重点排查线约 2.5~3 倍）
转化速率      = 订单 ÷ 运行天数 × 7   （≥1~2 单/周 → 收割）
日预算下限    = (1 ÷ CVR) × CPC
广告位判定     = 该位 ACoS ÷ 盈亏平衡 ACoS
                TOS > 1.15 降 / < 0.7 加；ROS > 1.0 降 / < 0.7 加；PP > 1.4 降
```
