# 亚马逊投放学习计划（4 周）

> 制定于 2026-09-21。**这份计划以我们已经建好的资产为教材**，不重复找资料。

---

## 零、先看清一件事：投放能力分两半，一半能学，一半只能练

这是整个计划的核心认知，先说清楚，否则会浪费大量时间。

| | 能「学」的部分 | 只能「练」的部分 |
|---|---|---|
| **是什么** | 概念、公式、机制、流程、边界 | 判断力、阈值感、类目直觉 |
| **有没有标准答案** | 有，可验证 | 没有，只有「在什么条件下更合理」 |
| **怎么获得** | 读 + 算 + 复现 | 用真实数据反复做决策 + 拿到结果反馈 |
| **大概占比** | **约 40%** | **约 60%** |

**危险在于**：网上绝大多数内容把第二类包装成第一类 —— 用「必须」「一定」「黄金」这类词，卖的是不确定的东西。
这也是为什么我们花六轮去验证那些阈值：**能验证的才算知识。**

**本计划的目标**：
- 4 周内把「能学的 40%」学扎实（这部分有确定答案）
- 同时建立「练 60%」的方法和反馈回路

## 第 0 步：自测（30 分钟，决定从哪开始）

**别跳过。** 下面 8 题答不上来的，对应章节就是你的起点。

1. ACoS 和 TACoS 分别除以什么？为什么 TACoS 上升不一定坏？
2. 售价 $39.99、成本 $8、FBA $7.5、头程 $3、佣金 15%、退货率 5%，**盈亏平衡 ACoS 是多少**？
3. 承上，若转化率 8%、目标 ACoS 25%，**可接受 CPC 是多少**？
4. 广泛/词组/精准三种匹配，**各自承担什么任务**？为什么不能只开一种？
5. 搜索词和关键词的区别？为什么要看搜索词报告而不是关键词报告？
6. 一个词 20 次点击 0 单，**该不该加否定**？（想清楚「取决于什么」）
7. 广告点击多但不出单，**怎么判断是流量问题还是 Listing 问题**？
8. 大促后为什么不能「恢复日常广告」就完事？

**判分**：
- 8 题都对 → 直接跳到第 3 周
- 4~7 题对 → 从第 1 周开始
- 0~3 题对 → 第 1 周放慢，重点打地基

> 第 2、3 题可以用工具对答案：
> ```bash
> node scripts/ads_opt.mjs calc --price 39.99 --cost 8 --fba 7.5 --first-leg 3 \
>   --commission-rate 15 --return-rate 5 --target-margin 15 --cvr 8
> ```
> （在 `amazon-ads-optimization` 仓库）

## 第 1 周：地基 —— 语言、算账、结构

**目标**：能看懂任何一份广告报表；能手算任何产品的盈亏平衡 ACoS 和可接受 CPC。

### Day 1–2：术语与机制

| 要掌握的 | 教材 |
|---|---|
| ACoS / ROAS / TACoS / CPC / CTR / CVR / IS 的定义与关系 | `references/metrics.md` |
| SP / SB / SD 的区别与适用 | 官方指南 `sponsored-products-best-practices`（URL 加 `zh-cn` 可得中文版） |
| 匹配方式（广泛/词组/精准/否定） | `references/diagnosis.md` 第 3~4 层 |
| 广告位与加价（TOS / ROS / PP） | 同上 第 5 层 |
| 学习期是什么、为什么会重置 | 同上 第 2 层 |

**验收**：能用自己的话向外行解释「ACoS 和 TACoS 的区别」。

### Day 3–4：经济账（整个体系的地基）

**这是唯一能「算对」的部分，必须练到闭眼能算。**

- 盈亏平衡 ACoS 的**逐项扣除**（为什么必须扣头程和退货损耗）
- 目标 ACoS = 盈亏平衡 × 策略乘数（launch 1.40 / grow 1.10 / dominate 1.15）
- 可接受 CPC = 售价 × CVR × 目标 ACoS
- 动态点击阈值 = 1 ÷ CVR

**练习**：跑 5 个不同品类的参数，观察结果怎么变
```bash
node scripts/ads_opt.mjs calc --price <售价> --cost <成本> --fba <FBA> \
  --first-leg <头程> --commission-rate <佣金率> --return-rate <退货率> --cvr <转化率>
```
建议参数：低客单刚需品、高客单耐用品、服装（退货率高）、季节性品、配件（低价）

**验收**：任选一个产品，3 分钟内算出盈亏平衡 ACoS、目标 ACoS、可接受 CPC，并说明每个扣项的来源。

### Day 5–7：结构

- 广告活动 / 广告组 / 投放对象 的层级关系
- **一个活动一个目标**（为什么不能又测词又推新品又清库存）
- 四种匹配方式的**角色分工**（Auto 探索 / Exact 放大 / Broad 扩量 / Phrase 覆盖）
- **相关性四问**（投词前的准入检查）
- ASIN 分组规则（同品类、按价格区间与转化率分组）

**教材**：`references/playbooks.md` 的「建活动前 7 项准备」+「匹配方式的角色分工」

**验收**：给你一个新品 + 10 个候选词，画出完整活动结构图，说明每个活动承担什么任务。

## 第 2 周：读数 —— 诊断

**目标**：对一份陌生的搜索词报告，独立产出 P0/P1/P2 动作清单。

### Day 8–9：九层诊断框架

顺序**不能跳**，因为上层问题会掩盖下层：

```
第 0 层  份额漏斗（SQP）   ← 先判断「该不该调广告」
第 1 层  店铺 / 账户
第 2 层  广告活动
第 3 层  广告组 / 关键词
第 4 层  搜索词
第 5 层  广告位
第 6 层  时段
第 7 层  大促期指标解读
第 8 层  新增需求分析
```

**教材**：`references/diagnosis.md` 全部（22KB，最核心的一份）

**重点理解第 0 层的意义**：防止把「转化问题」当「出价问题」而不断加价 —— 这是投放里最贵的错误。

### Day 10–11：实操诊断

**用真实数据练**：
```bash
node scripts/ads_opt.mjs diagnose --file <搜索词报告.csv> \
  --target-acos 25 --break-even-acos 41
```

**要求**：
1. 先**自己**看数据，手工列出你觉得该动哪些词、怎么动
2. 再用脚本跑，对比差异
3. **重点分析差异** —— 哪里你判断错了、哪里脚本机械了

> 这一步比读文档重要十倍。工具的作用是让你看到自己的偏差。

### Day 12–13：区分流量问题 vs Listing 问题

新手最容易搞错的地方 —— 该否词时去改图片，该改图时又去扩词。

**两层对比法**：
- 横向比流量：高点击零单词 vs 稳定出单词，比搜索意图/匹配方式/广告位/投放类型
- 纵向比 ASIN：广告转化差但**业务报告 Unit Session % 稳定** → 流量质量问题；两者同时降 → Listing 问题

**教材**：`references/diagnosis.md` 的「两层对比法」

### Day 14：验收

给一份 30+ 行的陌生搜索词报告，1 小时内产出动作清单，每条写清：
- 对象（哪个词 / 哪个活动）
- 动作（改到什么值）
- **依据**（引用哪条规则 + 什么数据）
- 优先级（P0/P1/P2）

## 第 3 周：决策 —— 动作与阈值

**目标**：不只「能看出问题」，而是「敢下判断，且知道自己在赌什么」。

### Day 15–16：动作库与分级

| 级别 | 动作 | 执行方式 |
|---|---|---|
| 只读 | 查数、诊断、生成方案 | 直接做 |
| 低风险写 | 加否定词、暂停明确亏损词 | 说明依据后执行 |
| 中风险写 | 改出价（±30% 内）、广告位加价一档 | **必须逐条确认** |
| 高风险写 | 建/删活动、改匹配方式、批量改 >20% | **必须确认 + 影响预估 + 回滚方案** |

**教材**：`references/actions.md`

**核心纪律**（要背下来）：
- 单次批量变更 ≤ 对象总量的 20%
- 学习期内（<3 天，保守 7 天）不调出价与结构
- **没有改前值就不要执行写操作**（无法回滚）
- 库存 <30 天销量 → 停止所有加投

### Day 17–18：阈值背后的证据

**这天的目的不是背阈值，是学会「怎么判断一个说法该不该信」。**

打开 `references/verification.md`，看六轮验证怎么做的：
- 每个阈值都标了证据来源与强度
- 有些标成「经验起点，未多源验证」
- 有 3 处**推翻了自己原本的写法**

**要求**：挑 3 条阈值，自己独立验证一遍。

> 这项能力的价值**远超记住任何阈值** —— 阈值会随类目和平台变化，判断信息可靠性的能力不会。

### Day 19–20：场景化

8 个场景手册：新品冷启动 / 成熟品提效 / 旺季大促 / 清库存 / 防守竞品 / 多站点 / 季节性 / 断货

**重点理解**：**同一个 ACoS，目标不同结论完全相反**。
- 清库存期 ACoS 高于盈亏平衡线可能是对的
- 推新品期 TACoS 上升也未必是坏事

**教材**：`references/playbooks.md`

### Day 21：决策演练

**场景**：给定一个产品的完整报表 + 目标（如「3 个月内做到日销 30 单且不亏」）

**产出**：完整投放方案
- 盈亏平衡与目标 ACoS 的推导
- 活动结构与初始出价
- 前 30 天的调整节奏
- 每一步的止损条件

## 第 4 周：复盘与进阶

### Day 22–23：报告体系

日报（只看异常）/ 周报（优化动作）/ 月度（目标校准）。

**关键**：日报**不因单日波动调出价**；周报必须包含「上周动作复盘」（预期 vs 实际）。

**教材**：`references/reporting.md`

### Day 24–25：大促复盘

- 三维度九问框架
- **自然权重验证法**（关广告掉排名 = 结构不稳；降广告仍稳住 = 自然权重已形成）
- 大促后防守型结构（30% 核心词 / 50% 长尾词 / 20% 防守词）
- 观察名单机制

**教材**：`references/peak-event-review.md`

### Day 26–27：份额视角（需品牌备案）

SQP 份额漏斗的**断崖定位法**：

| 断崖位置 | 病因 | 不要做什么 |
|---|---|---|
| 点击份额 < 曝光份额 | 主图/价格/评分 | ❌ 不要加价 |
| 加购份额 < 点击份额 | 详情页/卖点 | ❌ 不要扩量 |
| 购买份额 < 加购份额 | 价格/运费/优惠券 | ❌ 不要怪广告 |

**教材**：`references/sqp-framework.md`

### Day 28：学「什么时候不该相信模型」

用 `jev-ads-analysis` 做影子对照，理解：
- 规则层为什么是主路径（可追溯），模型为什么只能是影子（黑盒概率）
- **分歧率过高时先怀疑设计，而不是庆祝发现分歧**
- 什么条件下不能用决策模型（答案空间无法穷举 / 是算术不是语义判断 / 低频）

**这不仅是投放知识，是「如何与 AI 协作做决策」的通用能力。**

## 贯穿四周的三件事

### 1. 每周跑一次真实数据

| 数据集 | 位置 |
|---|---|
| 45 词搜索词报告（含真实 CPC/ACoS 分布） | `jev-ads-analysis/work/dataset-redhen-45.csv` |
| 12 词示例 | `amazon-ads-optimization/examples/sample-search-term-report.csv` |
| 广告位报告示例 | 同上 `sample-placement-report.csv` |
| SQP 份额报告示例 | 同上 `sample-sqp-report.csv` |

### 2. 每周产出可检验的交付物

| 周 | 交付物 | 检验标准 |
|---|---|---|
| 1 | 5 个品类的经济账 | 数字正确、扣项齐全 |
| 2 | 陌生报表的动作清单 | 每条有依据、优先级合理 |
| 3 | 完整投放方案 | 含止损条件与回滚方案 |
| 4 | 周报 + 大促复盘 | 含「上周动作复盘」（预期 vs 实际） |

### 3. 建立「证据意识」

**每次看到一条投放「知识」，问三个问题：**
1. 这是**官方口径**、**多源验证**，还是**个人经验**？
2. 它的**适用范围**是什么？（类目 / 客单价 / 阶段）
3. 有没有**反例**？

> `verification.md` 就是这三个问题的完整示范 —— 32 个子项达到多源验证，5 条被降级为「经验起点」。

## 什么不该学（我们踩过的坑，你可以跳过）

| 别学 | 为什么 |
|---|---|
| 「黄金时段」「权重论」等玄学 | 无法证伪。我们验证过：**分时的正确做法是降预算降出价，不是暂停** |
| 把单一来源当共识 | 流传很广的「Product Pages 加价」，**独立实现明确否定** |
| 固定阈值照搬 | `1÷CVR` 优于「10 次点击」；`ACoS > 1.15×盈亏线` 优于「ACoS>40%」 |
| 2020~2022 年的打法 | 算法已变（A9 → COSMO → AI 推荐），很多老方法失效 |
| 只看 ACoS | 官方自己都有一节「Why you shouldn't focus too much on ACOS」 |

## 一句话总结

**第 1 周学「算」，第 2 周学「看」，第 3 周学「判」，第 4 周学「复盘」。**

能学的那 40%，4 周够扎实；剩下的 60%，本计划只提供方法和反馈回路 —— 那部分只能靠真实数据喂出来。
